# Disease Spread Simulation

**Machine Learning & Data Science Club | Baruch College**

We built a virtual town of 100 people to ask how measles, influenza and COVID-19 spread in the model, and how vaccination and staying home change the results. The simulation is for learning.

## Weekly assignments

| Week | Assignment | What we do |
| --- | --- | --- |
| 1 | [SIR and SEIR](assignments/Week_01_SIR_SEIR_Models.ipynb) | Build and compare two basic disease models. |
| 2 | [Virtual town](assignments/Week_02_Assignment.ipynb) | Track residents and their meetings over 60 days. |
| 3 | [Compare diseases](assignments/Week_03_Compare_Diseases.ipynb) | Use the same town to compare three disease scenarios. |
| 4 | [Interactive controls](assignments/Week_04_Intereactive_Sliders.ipynb) | Add vaccination and stay-home sliders, graphs and a CSV export. |
| 5 | Machine learning | Use linear regression and a decision tree to predict outcomes from simulation runs. |
