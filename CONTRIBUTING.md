# How we'll work together on GitHub

This is our shared project. I'll post our weekly assignments, and we'll each contribute to building the actual simulation.

1. Accept the GitHub collaborator invitation and clone this repository (cloning already downloads it).
2. Before starting an assignment, create your own branch, for example `alex-week1`.
3. Read the assignment in `assignments/`. Save your own completed file under `student_work/` with your name and week in the filename.
4. Commit your changes and push **your branch**, not `main`.
5. Open a pull request to `main`, and briefly say what you completed, how you tested it, and where you're stuck.
6. I'll review, ask for changes if needed, and merge approved work.

Please don't push directly to `main`. We should discuss changes to shared files first. We'll use research notes to separate sourced facts, calculations, and model assumptions.

You do not need a separate repository unless we decide to use forks later.
