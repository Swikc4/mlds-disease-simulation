# Research and sources

We'll keep our disease sources, parameter notes, and data descriptions here.

For every number we use, record the disease, parameter, value, units, source URL, and whether it is **SOURCED**, **DERIVED**, or an **ASSUMPTION**. Explain derived values and assumptions in plain language.

Our starting sources come from the project proposal: CDC influenza and measles pages, published COVID-19 and measles papers, and historical Johns Hopkins COVID-19 data for the optional extension. We will check each source before using values in our simulation.
