## Choosing tasks

Everyone can choose tasks based on their interests, experience, and what they want to learn. We will discuss task choices as a group to make sure the work is covered fairly. Tasks can change as the project progresses.

## Project priorities

Our goal is to build a working educational disease simulation with clear graphs and explanations. We plan to compare three diseases and evaluate basic machine learning models using simulated data.

If time allows, we may add a historical NYC COVID 19 comparison or try more advanced machine learning. We will prioritize a tested, understandable project over extra features.
