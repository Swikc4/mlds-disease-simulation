# Learning Materials

This folder is for learning, not for completed assignments. You do not need prior Python or statistics experience to start here.

Each week will have its own materials, so you can learn what you need without reading everything at once.

## Start here

**Week 1: Python, basic math, and reading graphs**
- [Python basics](Week_01/01_Python_Basics.md) — start here if you have never coded.
- [Math and data basics](Week_01/02_Math_and_Data_Basics.md) — numbers, rates, fractions, and graphs.
- [Practice and helpful links](Week_01/03_Practice_and_Resources.md) — short exercises and beginner tutorials.

**Future weeks:** We'll add a new `Week_02/`, `Week_03/`, etc. folder when we reach that topic. You do not have to study future material yet.

## How to use these notes
1. Read one section at a time and try the small examples.
2. Change numbers or words in the examples and see what happens.
3. Attempt the practice questions before checking your work with a teammate.
4. Open the separate assignment only when you're ready. These notes do **not** solve the assignment.
5. If something is confusing, ask in the group; questions are welcome.

Aim to explain *what a line does* and *why you used it* in your own words. You do not have to memorize syntax or understand advanced mathematics right away.

Project-specific scientific sources and modeling assumptions are listed separately in [research](../research/README.md). These general learning notes are not evidence for disease-specific claims.
