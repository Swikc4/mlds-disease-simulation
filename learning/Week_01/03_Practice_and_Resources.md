# Week 1 — Practice and Beginner Resources

These are **optional warm-ups**. They are not the Week 1 assignment and do not contain its solution.

## Before you begin
If you are completely new to Python, start with [Python basics](01_Python_Basics.md), then read [Math and data basics](02_Math_and_Data_Basics.md). Try each example in a new notebook. Change a value, rerun the cell, and describe what changed.

## Practice: small independent tasks
1. **Variables:** Store the price of one notebook and the number purchased. Calculate the total price.
2. **Lists:** Make a list of five quiz scores. Print the first score and how many scores there are.
3. **Loops:** Use a `for` loop to print the numbers 0 through 4.
4. **Functions:** Write a function that converts hours into minutes. Try it with two inputs.
5. **Graph:** Plot a fictional person's steps over four days. Add a chart title and axis labels.
6. **Math:** A class has 8 laptops for 25 students. What percentage of students could each use one laptop at the same time?
7. **Explain:** Pick three lines from your own practice code. Write one sentence about what each line does.

If stuck, reread the relevant section or ask a teammate to explain the idea. Avoid copying an answer you cannot describe yourself.

## Questions for group discussion
- Which line in your practice code was hardest to understand?
- How would you explain a variable to someone from a nontechnical major?

- What chart labels would help someone who has not seen your data?

The goal is progress and understanding, not speed.
